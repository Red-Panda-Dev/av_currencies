# AV.by Валюты — iOS (Safari)

Userscript-версия `AV.by Валюты` для Safari на iPhone/iPad: автоматически заменяет цены на AV.by из белорусских рублей (BYN) в выбранную валюту — USD, EUR или RUB — по курсам публичного API Национального банка Республики Беларусь.

На iOS нельзя установить обычное WebExtension-расширение, поэтому здесь пользовательская логика распространяется как userscript через менеджер userscript-ов для Safari. Скрипт полностью автономен: это один файл `av-currencies.user.js` без сборки, бандлера и зависимостей от кода расширения.

Основной проект — браузерное расширение для Firefox и Chrome — описан в [`README.md`](../README.md).

## Возможности

- Замена цен на AV.by из BYN в USD, EUR или RUB.
- Возврат к оригинальным ценам в BYN при выборе валюты `BYN`.
- Поддержка цен в списках объявлений, карточках автомобилей и диапазонах «от/до».
- Автоматическое обновление курсов НБРБ — TTL кэша 4 часа.
- Работа с кэшированными курсами, если API временно недоступен.
- Переключатель валют прямо на странице AV.by — без popup, виджет встроен в интерфейс сайта.
- Аннотация `, всего N дней в продаже` в карточках объявлений — как в расширении.

## Как пользоваться

1. Установите менеджер userscript-ов для Safari (например, бесплатное приложение [Userscripts](https://apps.apple.com/app/userscripts/id1463298887)).
2. Включите его в **Настройки → Safari → Расширения** и разрешите доступ к сайту `av.by`.
3. Откройте [`av-currencies.user.js`](https://raw.githubusercontent.com/Red-Panda-Dev/av_currencies/main/ios/av-currencies.user.js) в Safari на iPhone и нажмите «Установить» в менеджере.
4. Откройте или обновите страницу на `https://av.by/` — на странице появится переключатель валют `BYN / USD / EUR / RUB`.
5. Выберите валюту — цены на странице будут заменены сразу, без перезагрузки.

## Как это работает

### Файл `av-currencies.user.js`

Один самодостаточный IIFE: без `import`/`export`, сборки и бандлера; устанавливается как единый файл.

Функции:

- `@match` ограничен `av.by` и поддоменами; сетевой доступ — только к `api.nbrb.by` (`@connect`).
- Загружает курсы НБРБ через `window.fetch` с таймаутом 10 секунд; если менеджер userscript-ов предоставляет `GM.xmlHttpRequest` / `GM_xmlhttpRequest` — использует их как fallback.
- Хранит курсы и выбранную валюту в `localStorage` страницы (`avc.ratesData.v1`, `avc.selectedCurrency.v1`), а не в `browser.storage.local`.
- Обновляет курсы по TTL 4 часа; при ошибке API не перезаписывает последние валидные курсы, а показывает ошибку в виджете.
- Находит элементы цен, сохраняет оригинальный BYN-текст и конвертирует его в выбранную валюту; переключение валюты восстанавливает оригинал без переустановки.
- Обрабатывает динамически добавленные элементы через `MutationObserver`.
- Дополняет статистику карточек данными из `__NEXT_DATA__` (`всего N дней в продаже`).
- Показывает встроенный в страницу виджет (`#avc-panel`) с кнопками валют; обновления DOM — только через `textContent` / `classList`.
- Селекторы цен и чистые функции конвертации — ручные копии из `src/content/avby.js` и `src/lib/rates.js`; их меняют синхронно во всех копиях.

## Приватность

- Скрипт обращается только к `https://api.nbrb.by` за курсами валют.
- Выбранная валюта и кэш курсов хранятся локально в `localStorage` страницы AV.by.
- VIN-функция, пользовательские курсы и любые другие внешние серверы отсутствуют.

## Отличия от расширения

| Возможность | Расширение (Firefox/Chrome) | iOS userscript |
| --- | --- | --- |
| Замена цен BYN → USD/EUR/RUB | Да | Да |
| Автообновление курсов НБРБ | Каждые 4 часа | TTL 4 часа |
| Кэш при недоступности API | Да | Да |
| Хранилище | `browser.storage.local` | `localStorage` |
| Управление | Popup расширения | Виджет на странице |
| Конвертер валют | Да | Нет |
| Пользовательские курсы | Да | Нет |
| Обмен VIN-кодами | Да (по умолчанию выключено) | Нет |
