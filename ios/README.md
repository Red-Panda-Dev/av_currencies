# AV.by Валюты — Safari iOS (userscript)

Порт функциональности расширения на **Safari для iPhone/iPad** в виде userscript-а.
На iOS расширения-манифесты V3 не подходят — пользовательскую логику проще
раздать через менеджер userscript-ов, поэтому здесь отдельный файл.

## Что делает

Заменяет цены на страницах `av.by` из BYN в USD / EUR / RUB по курсам НБРБ
(`api.nbrb.by`, TTL 4 часа, кэш в `localStorage`).

## Установка

1. Установи менеджер userscript-ов для Safari iOS
   (например, [Userscripts](https://apps.apple.com/app/userscripts/id1463298887)).
2. Включи его в **Настройки → Safari → Расширения**.
3. Открой [`ios/av-currencies.user.js`](av-currencies.user.js) в Safari на iPhone
   и нажми «Установить» в менеджере.
4. Зайди на `av.by` — переключатель валют появится в интерфейсе.

## Отношение к основному расширению

Скрипт самодостаточный: свой fetch курсов, свой кэш, свой UI-переключатель.
Он **не подменяет** Chrome/Firefox-расширение, а даёт эквивалент для iOS,
где нельзя поставить обычное WebExtension.
