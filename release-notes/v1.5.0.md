# VIN по желанию

## Коротко

В этой версии добавили опциональную функцию VIN. Если включить ее в попапе, расширение может показывать полный VIN для объявления, когда он уже есть в общей базе, и отправлять VIN, который пользователь сам открыл на AV.by. Также расширение стало лучше обрабатывать некоторые цены в блоках с ежемесячными платежами.

---

## Что изменилось

### Для пользователей AV.by

* **VIN в карточке авто:** появилась настройка, которая может подставлять полный VIN, если он уже сохранен для этого объявления. По умолчанию функция выключена.
* **Обмен найденными VIN:** когда пользователь сам раскрывает VIN на странице, расширение может отправить его для подтверждений сообщества. Это помогает другим пользователям увидеть тот же VIN позже.
* **Больше цен распознается:** расширение теперь обрабатывает еще один формат ежемесячной цены в карточках AV.by, где сумма находится в отдельном выделенном элементе.

### Попап и настройки

* **Отдельная настройка VIN:** чекбокс VIN вынесен в понятный блок в попапе. Рядом добавлена ссылка на описание логики работы.
* **Аккуратнее отображение:** ширина попапа стала фиксированной, а длинные статусы и подписи должны меньше ломать внешний вид.

### Приватность и данные

* **VIN только по выбору:** функция VIN работает только после включения в попапе.
* **Понятнее, что передается:** для VIN-функции добавлено описание логики обмена и подтверждений. В Worker отправляются данные объявления и полный VIN, а идентификатор запроса используется в хэшированном виде.

### Работа в браузере

* **Обновленные пакеты:** сборки для Firefox и Chrome-based браузеров пересобраны с новой функцией VIN.
* **Чище архивы:** в готовые пакеты больше не попадают исходные и промо-версии иконок, которые не нужны для установки расширения.

---

## Исправили

* Исправили ситуацию, когда VIN мог прийти раньше, чем кнопка VIN появлялась на мобильной странице AV.by. Теперь сохраненный VIN применяется и к элементам, которые добавились позже.
* Убрали неудобство, когда подставленный VIN оставался внутри кнопки. Теперь он заменяет кнопку обычным текстом, который проще выделить.

---

## Технически

* Добавлен отдельный Worker для VIN-функции: он хранит VIN по объявлению, возвращает сохраненное значение и учитывает подтверждения чтения и записи.
* Добавлены проверки для фоновой логики, страницы AV.by, попапа и Worker, чтобы выпускать функцию VIN с меньшим риском регрессий.
* Обновлены команды для тестирования и деплоя Worker, а также правила сборки пакетов расширения.

---

## Что это значит для пользователя

Если вам нужна VIN-функция, ее можно включить в попапе и пользоваться ей на страницах объявлений AV.by. Если функция не нужна, ничего менять не требуется: по умолчанию она выключена, а конвертация цен продолжает работать как раньше.

---

## Полный список изменений

* Добавлена опциональная VIN-функция в расширение.
* Добавлен Worker для хранения, получения и подтверждения VIN.
* Добавлена настройка VIN в попапе и ссылка на описание логики.
* Улучшена обработка VIN на мобильных страницах и замена кнопки на обычный текст.
* Добавлена поддержка еще одного формата ежемесячной цены на AV.by.
* Пересобраны пакеты для Firefox и Chrome-based браузеров.
* Из пакетов исключены лишние исходные и промо-иконки.

# Optional VIN Sharing

## Summary

This release adds an optional VIN feature. When enabled in the popup, the extension can show a full VIN for a listing if it already exists in the shared database, and it can submit a VIN that the user revealed on AV.by. The extension also handles one more monthly-price format on AV.by cards.

---

## What changed

### For AV.by users

* **VIN on vehicle pages:** there is a new setting that can insert the full VIN when it is already saved for that listing. The feature is off by default.
* **Sharing found VINs:** when a user reveals a VIN on the page, the extension can submit it for community confirmations. This can help other users see the same VIN later.
* **More prices detected:** the extension now handles another monthly-price format on AV.by cards, where the amount is placed inside a separate highlighted element.

### Popup and settings

* **Separate VIN setting:** the VIN checkbox now has its own clear block in the popup. A link to the logic description was added next to it.
* **Cleaner display:** the popup width is now fixed, and long statuses or labels should be less likely to break the layout.

### Privacy and data

* **VIN only by choice:** the VIN feature works only after it is enabled in the popup.
* **Clearer data explanation:** the VIN sharing and confirmation logic is now documented. The Worker receives listing data and the full VIN, while the request identifier is used in hashed form.

### Browser experience

* **Updated packages:** Firefox and Chromium-based browser builds were regenerated with the new VIN feature.
* **Cleaner archives:** installation packages no longer include raw and promotional icon files that are not needed to use the extension.

---

## Fixed

* Fixed a case where the VIN could arrive before the VIN button appeared on a mobile AV.by page. Now the saved VIN is also applied to elements inserted later.
* Removed an inconvenience where an inserted VIN remained inside a button. It now replaces the button with plain text that is easier to select.

---

## Technical notes

* Added a separate Worker for the VIN feature: it stores VINs by listing, returns saved values, and tracks read and write confirmations.
* Added checks for background logic, AV.by pages, the popup, and the Worker to reduce the risk of regressions around the VIN feature.
* Updated Worker test and deploy commands, along with extension package build rules.

---

## What this means for users

If you want the VIN feature, you can enable it in the popup and use it on AV.by listing pages. If you do not need it, there is nothing to change: it is off by default, and price conversion continues to work as before.
