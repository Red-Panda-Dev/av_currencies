# Наведён порядок

## Коротко

В этой версии мы навели порядок внутри расширения. Файлы исходного кода переехали в отдельную папку, сборка стала проще и одинаковой для Firefox и Chrome-based браузеров. Для пользователей AV.by ничего не изменилось — расширение работает так же, как раньше.

---

## Что изменилось

### Работа в браузере

* **Проще установка и сборка:** процесс подготовки расширений для Firefox и Chrome стал одинаковым. Меньше риска ошибок при выпуске новых версий.
* **Чистые архивы:** в готовые сборки больше не попадают файлы, которые нужны только разработчикам. Архивы для установки стали аккуратнее.

---

## Технически

* Исходный код перенесён в папку `src/` — так понятнее, где код расширения, а где вспомогательные файлы.
* Скрипты сборки для Firefox и Chrome теперь используют общие утилиты — меньше дублирования, проще поддерживать.
* Makefile упрощён — основные команды теперь вызываются через npm-скрипты.
* Разрешения расширения сокращены до минимально необходимых.

---

## Что это значит для пользователя

Ничего не изменилось в том, как вы пользуетесь расширением. Цены на AV.by продолжают конвертироваться как раньше, попап с курсами работает как обычно. Внутренний порядок упростит выпуск будущих обновлений.

# Cleaner Structure

## Summary

This release focuses on internal organization. Source files moved into a dedicated directory, and the build process became simpler and consistent across Firefox and Chrome-based browsers. For AV.by users, nothing changes — the extension works exactly as before.

---

## What changed

### Browser experience

* **Simpler build and install:** the packaging process for Firefox and Chrome is now the same. Less risk of mistakes when releasing new versions.
* **Cleaner archives:** files meant only for developers no longer end up in installation packages. The build outputs are tidier.

---

## Technical notes

* Source code moved into the `src/` directory — clearer separation between extension code and supporting files.
* Firefox and Chrome build scripts now share common utilities — less duplication, easier to maintain.
* Makefile simplified — main commands now run through npm scripts.
* Extension permissions reduced to the minimum required set.

---

## What this means for users

Nothing changes in how you use the extension. Prices on AV.by continue to convert as before, the popup with exchange rates works as usual. The internal cleanup will make future updates easier to release.

---

## Full changelog

* Source files reorganized into `src/` directory
* Build scripts unified with shared packaging utilities
* Added standalone Firefox build script
* Build outputs cleaned up — no more developer-only files in packages
* Makefile simplified to use npm scripts
* Extension host permissions reduced to minimum required
* Test paths updated for new source layout
